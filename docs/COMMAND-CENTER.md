# مركز قيادة الطالب — Student Command Center

> صفحة `/student` — أُعيد بناؤها بالكامل (17 أكتوبر 2026، كوميت `bd091b5`) من «داشبورد بسيط» إلى **مركز قيادة** داكن (bento سينمائي، glass، زمردي).
> هذا المستند يوثّق: مصادر كل رقم، قواعد التصميم، التفاعلات، والودجت **المؤجّلة بأمانة** — لأي مطوّر أو وكيل يلمس الصفحة بعد اليوم.

## 1) المبدأ الحاكم: كل رقم من السيرفر

**ممنوع أي mock أو رقم ملفق في هذه الصفحة.** أي ودجت مفيهوش داتا حقيقية على السيرفر يتأجّل ويُوثَّق هنا — لا يُقلَّد.

- كل الأرقام تُشتق من استجابات الـAPI الحية وقت فتح الصفحة.
- كل التواريخ المعروضة (`unlockedAt` / `submittedAt` / `startsAt`) مُنتَجة من السيرفر ولا تُصنَّع محليًا.
- الحالات العربية تُبنى من أعمدة حالة إنجليزية حقيقية (map ثابت، مع fallback للنص الأصلي لو القيمة غير معروفة).

## 3) التفاعلات

- **Focus Mode**: زر في الدوك → `window.dispatchEvent(new CustomEvent("sanad:focus", { detail }))` → كلاس `cc-bento--focus` يخفت كل الكروت (18% + blur 4px، انتقال 400ms) عدا `.cc-keep` (الهيرو + كارت «أكمل التعلم»). يخرج تلقائيًا عند مغادرة الصفحة.
- **⌘K**: كبسولة في الدوك تفتح Command Palette (زجاج داكن). إجراءات الطالب: لوحتي/كورساتي/واجباتي/اختباراتي/كتالوج الكورسات.
- **قاعدة حرجة**: كل تنقّل داخل منطقة الطالب يمر بـ`router.push` (SPA) — الجلسة in-memory و**أي full reload = تسجيل خروج**. (تم إصلاح `window.location.assign` القديم في نفس الدفعة.)
- **حالات**: Skeletons أثناء التحميل (بنفس شبكة الـbento) · Empty state (كتاب مفتوح + «اختر كورسك الأول»).
- **حماية عدّادات**: `useCountUp` وعدّاد الحلقة يستقرّان فورًا لو التاب مخفي (`document.hidden`) — لا أرقام معلّقة على صفر في السكرين شوت/الخلفية.

## 4) قواعد التصميم (الملزمة للصفحة دي)

- الخلفية `ink-950` + شبكة 2.8% + دائرتان زمرديتان `blur(110px)` بـdrift بطيء (متوقف باحترام `prefers-reduced-motion`).
- الكروت: `rgba(255,255,255,0.03)` + `blur(20px)` + حد أبيض 8% + راديوس 32 + gap 24. الدوك: زجاج 3% + blur 24 + كبسولة ⌘K + مؤشر متحرك.
- الزمردي فقط (`--color-action` وما حولها) — **ممنوع أزرق أو تدرجات عشوائية**. على الداكن تُستخدم درجات فاتحة للنص (`#34d399`/`#6ee7b7`).
- ممنوع نص أصغر من 11px، أهداف اللمس ≥40px، أرقام `tnum`، بلا bounce، بلا alert.
- الثيم الداكن **محصور بصفحة `/student`** — باقي صفحات الطالب فاتحة، والدوك يتبدّل حسب المسار.
- كل التنسيق في `apps/web/app/globals.css` تحت بلوك `23c. STUDENT COMMAND CENTER` (كلاسات `.cc-*` و`.sd-*`).
